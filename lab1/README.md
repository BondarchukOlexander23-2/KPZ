У класі [Money](task1/Money.py) було використано наступні принципи: SRP (Single Responsibility Principle),
[Encapsulation of Behavior](./task1/Money.py#L23), DRY (Don't Repeat Yourself) а також було дотримано принципів ООП та інкапсуляції. <br>

У класі [Product](task1/Product.py) дотримано принципів ООП, інкапсуляції, SRP, принцип захисту від некоректних даних.

У класі [Reporting](task1/Reporting.py) дотримано принципів ООП, інкапсуляції, SRP, OCP(Open/Closed Principle), принцип узгодження даних.

У класі [Warehouse](task1/Warehouse.py) дотримано принципів ООП, інкапсуляції, SRP, принцип захисту від некоректних даних, [принцип узгодження даних](task1/Warehouse.py#L22-L23).

У класі [Category](task1/Category.py) дотримано принципів ООП, інкапсуляції, SRP, принцип захисту від дублювання, принцип перевірки перед виконанням дії, OCP

У класі [Discount](task1/Discount.py) дотримано принципів ООП, інкапсуляції, Data Validation, SRP, принцип мінімізації помилок, принцип ефективності, OCP, Transparency
